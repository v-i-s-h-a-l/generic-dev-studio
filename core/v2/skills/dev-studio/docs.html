Studio v2 umbrella command

/dev-studio

Canonical entrypoint for Studio v2 role dispatch. The router resolves a role, applies compatibility aliases from the deleted v1 surfaces, and then hands execution to the role contract.

Quick Start Roles Resolution Cutover Boundaries Evidence

Quick Start

Put the role after /dev-studio. If no role token is present, the invocation defaults to manager for conversational shaping and status.

/dev-studio manager resume-plan /dev-studio worker <contract> /dev-studio reviewer review /dev-studio perf profile /dev-studio release-manager

Current traffic surface

A10 records v2 as the active surface. Former top-level names now work only as compatibility role aliases under /dev-studio.

Canonical Roles

manager

Owns intake, prioritization, lifecycle state, dispatch, status, user escalation, and final acceptance routing.

activealiases: chanakya, coordinator, orchestrator

worker

Implements one bounded task contract in an isolated worktree.

activealiases: achilles, implementer

reviewer

Verifies plan or spec compliance, code quality, safety gates, and contract adherence.

activealiases: argus, verifier

perf

Investigates performance, battery, memory, thermal, and instrumentation evidence.

activealiases: apollo, performance, performance-engineer

planner

Converts shaped intent into executable plans, dependency graphs, acceptance criteria, and worker contracts.

reservedaliases: architect, luban, lu-ban

qa-engineer

Produces and executes automated test contracts beyond the worker's local checks.

reservedaliases: qa, chiron, synthetic-qa

flow-tester

Produces human or manual exploratory flow checklists tied to builds and releases.

reservedaliases: flow, manual-qa, exploratory-tester

release-manager

Assembles beta and production release packets, verifies prerequisites, and drafts release notes.

reservedaliases: release, shipper

host-adapter

Exposes host capabilities as data and executes portable role invocations.

reservedaliases: adapter, host

operator

Holds human authority for irreversible, ambiguous, or externally visible decisions.

non-routablealiases: user, human, owner

Resolution Order

  1. Explicit canonical role routes directly, such as /dev-studio worker <contract>.
  2. Compatibility alias resolves through scripts/v2-role-resolve.sh, such as /dev-studio achilles <contract>.
  3. Former top-level names remain aliases only when placed under /dev-studio.
  4. No role token routes to manager.

Unknown roles fail closed

Unknown role tokens exit before side effects. Alias normalization is case-insensitive and treats underscores or spaces as hyphens.

Router Boundaries

The umbrella router chooses a role contract. Mode procedure, authority checks, handoff validation, event emission, and project-profile commands are owned by the selected role or downstream primitive.

This page is the studio-layer command surface. It intentionally does not duplicate deleted v1 agent manuals or task-layer command tables.
